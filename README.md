# Jillian Cung Communications Portfolio

Static HTML/CSS/JS portfolio ready for GitHub and Render.

## GitHub
Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.

## Render
- Branch: main
- Root Directory: blank
- Build Command: blank
- Publish Directory: ./

The site uses Nunito from Google Fonts and embeds Canva presentations for photography work.
